📇 Contact Manager – Pink Theme

A stylish and user-friendly Contact Manager application built using Python Tkinter. This desktop application allows users to add, update, search, view, and delete contact information through an attractive pink-themed graphical interface.

📌 Project Overview

The Contact Manager is a GUI-based application designed to help users organize and manage personal or professional contacts efficiently. Users can store contact details such as name, phone number, email address, and address, making it easy to maintain and update contact records.

✨ Features
➕ Add new contacts
✏️ Update existing contacts
🗑 Delete contacts
🔍 Search contacts by name or phone number
📋 View all saved contacts
📂 Load contact details by selecting a contact
🧹 Automatic field clearing after operations
🎀 Attractive pink-themed user interface
⚠ Input validation for required fields
